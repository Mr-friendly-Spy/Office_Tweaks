# Office_Tweaks ⚙️✒️

Консольная утилита для автоматизации работы с офисными документами и изображениями.

## Установка и активация виртуального окружения Python в PyCharm 🔧
- Открыть Терминал в PyCharm
- Ввести в терминале:
 ```python -m venv venv```
- Активируем виртуальное окружение
 ```venv\Scripts\activate```
- После успешной активации виртуального окружения вы увидите (venv) слева от командной строки:
 ```(venv) PS C:\Users\Егор\PycharmProjects\Office_Tweaks>```
## Функциональность 📄

- Конвертация PDF в DOCX
- Конвертация DOCX в PDF  
- Сжатие изображений (JPEG, PNG, GIF)
- Удаление файлов по шаблону
- Управление рабочим каталогом
