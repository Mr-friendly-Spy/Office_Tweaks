# Office_Tweaks

Консольная утилита для автоматизации работы с офисными документами и изображениями.

## Функциональность

- Конвертация PDF в DOCX
- Конвертация DOCX в PDF  
- Сжатие изображений (JPEG, PNG, GIF)
- Удаление файлов по шаблону
- Управление рабочим каталогом

## Установка зависимостей

pip install -r requirements.txt
